# v1.0 Stable Release

`stock-research-v1.0.0` is a stable review-gated stock research Skill.

## Stable Capabilities

- Offline/local evidence workflow.
- Evidence package governance.
- Parser-readiness audit and evidence reconciliation.
- Controlled real-company quarantine sandbox.
- Quarantined ratio-only calculation guardrails.
- Review-gated report packets.
- QA, red-team, artifact hygiene, security boundary and release-candidate audits.

## Explicit Non-Goals

- No live XBRL extraction.
- No production iXBRL parser.
- No full real filing parsing.
- No automatic real-company production promotion.
- No broker, trading, order routing or credential workflow.
- No target price, buy/sell/hold, position size, portfolio action or research status.
- No public release without separate user approval.

## Public Readiness

Public-readiness status for v1.0 is `Needs user decision`. The repository should remain private unless the user explicitly approves public release after reviewing the public-readiness audit.
