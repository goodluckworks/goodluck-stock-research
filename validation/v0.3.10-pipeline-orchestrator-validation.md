# v0.3.10 Pipeline Orchestrator Validation

## 1. Scope

v0.3.10 adds an offline review-gated pipeline orchestrator that reuses local fixture/example packages and preserves existing gates. It does not add live extraction, production parsing, credentials, broker/trading integrations or investment conclusions.

## 2. Pipeline Modes

| Mode | Result | Notes |
|---|---:|---|
| `fictional_sandbox_full` | Pass | EXMP candidate -> workbench -> quality -> review -> promotion -> CSV sandbox -> ratio dry-run -> audit |
| `fictional_sandbox_partial` | Pass | EXMP partial-field sandbox with downstream impact |
| `real_company_review_only` | Pass | MRVL / NVDA / AVGO candidate, workbench, quality and review only |
| `blocked_real_company_promotion_attempt` | Pass | Tests verify promotion, CSV and dry-run blocked steps |
