# v3.0 Live Production Research System

## Purpose

v3.0 turns `goodluck-stock-research` into a usable live production equity research workflow while preserving strict research-only boundaries.

## How To Run

```bash
python3 goodluck-stock-research/production/cli.py research --ticker MRVL --mode fixture
python3 goodluck-stock-research/production/cli.py research --ticker MRVL --mode live --sec-only
python3 goodluck-stock-research/production/cli.py research --ticker NVDA --mode live --sec-only --market-data-csv path/to/prices.csv
python3 goodluck-stock-research/production/cli.py validate --run-dir goodluck-stock-research/examples/production_research/MRVL
```

## Source Manifest

Every run should preserve source identity, source reliability, status, checksum and caveats in a source manifest. If market data is unavailable or unreliable, the system must return `insufficient_market_data` instead of fabricating values.

## Data Quality

Review `data_quality_report.md` before using valuation or conclusion output. Low-quality, missing-source, unsupported-issuer or unresolved parser outputs must remain caveated or blocked.

## Valuation Assumptions

Valuation output must disclose assumptions and label fair value ranges as scenario output, not recommendation or trading instruction.

## Research Conclusion

Allowed research views:

- Constructive
- Neutral
- Cautious
- Negative
- Insufficient evidence

Every conclusion must include confidence, evidence basis, data-quality caveats and key risks.

## Not Supported

- Broker integration.
- Trading execution.
- Order routing.
- Portfolio allocation or position sizing.
- Personalized financial advice.
- Guaranteed returns.
- Hidden credential, API key, token, password or secret workflow.
