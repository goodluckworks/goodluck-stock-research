# Mapping Review Fixtures

These JSON files are local, artificial governance fixtures for v0.3.6.

- `mapping_review_approved.json` approves the fixture-only mapping registry for fictional EXMP promotion tests.
- `mapping_review_superseded.json` blocks promotion through supersession lifecycle checks.
- `mapping_review_rejected.json` blocks promotion through rejected lifecycle checks.
- `invalid_mapping_review_missing_evidence.json` demonstrates that approval without evidence is invalid.

They do not approve production XBRL extraction, live SEC parsing, real-company promotion or populated v0.2.x CSV generation.
