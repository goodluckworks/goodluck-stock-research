# v0.6 Controlled Real-Company Sandbox Gate

## 1. Positioning

v0.6 introduces a controlled, explicit and quarantined real-company sandbox gate.

It is not production XBRL extraction. It is not live extraction. It is not public-release readiness. It does not create investment data, company fact, target price, buy/sell/hold, position size or research status.

The controlled gate exists only to test whether a real-company-shaped review packet can move into a quarantined local calculation drill after explicit review approval.

## 2. Required Flow

```text
real-company review packet
  -> reviewer checklist
  -> quality score
  -> explicit real-company sandbox approval gate
  -> quarantined normalized CSV sandbox
  -> optional quarantined ratio dry-run
  -> audit report
  -> no investment conclusion
```

## 3. Explicit Invocation

The gate is off by default. A run must explicitly provide:

```bash
python3 goodluck-stock-research/pipeline/controlled_real_company_sandbox_gate.py \
  --mode controlled_real_company_sandbox \
  --allow-real-company-sandbox \
  --ticker MRVL \
  --quarantine-output \
  --review-batch <path> \
  --quality-score <path> \
  --candidate-package <path> \
  --approval-policy <path> \
  --output-dir goodluck-stock-research/examples/real_company_quarantine/MRVL
```

## 4. Quarantine Flags

Every quarantine output must preserve:

- `quarantined=true`
- `not_production_data=true`
- `not_investment_data=true`
- `not_company_fact_until_verified=true`
- `manual_review_required=true`
- `not_for_trading=true`
- `not_for_public_release=true`
- `no_recommendation=true`

## 5. Gate Requirements

The gate must verify:

- Review batch exists.
- Review batch status is `approved_for_quarantine`, not production approved.
- Quality score status is `ready_for_quarantine`.
- Checklist is complete.
- Mapping review status is approved and not superseded.
- Candidate package is traceable.
- Snapshot SHA-256 is consistent.
- Field provenance exists through candidate references.
- No blocking issues.
- No low-confidence approval below the policy threshold.
- No unresolved promoted fields.
- Ticker is allowlisted.
- Output path is the quarantine path.
- Public release is not approved.

## 6. Tracked Example Policy

v0.6 tracks only one real-company quarantine example:

- `goodluck-stock-research/examples/real_company_quarantine/MRVL/`

NVDA and AVGO remain blocked from tracked quarantine output in v0.6. Their blocked attempts may be tested only in temporary directories or exception paths.

## 7. Dry-Run Limits

Allowed:

- MRVL quarantined ratio dry-run only.

Forbidden:

- DCF.
- Peer comps.
- Implied expectations.
- Full research report.
- Investment conclusion.
- Target price.
- Buy/sell/hold instruction.
- Position size.
- Research status.

The dry-run banner must include:

```text
QUARANTINED REAL-COMPANY SANDBOX DRY-RUN
Not production data.
Not investment advice.
Not for trading.
Manual review required.
```

## 8. Public-Readiness

v0.6 is not public-ready by default. Public readiness remains:

```text
ready_for_public_release: No
reason: requires separate public-readiness approval
```
