# Evidence Reconciliation Policy

Every research artifact must be traceable from output back to evidence.

## Required Chain

1. Candidate value links to source locator.
2. Source locator links to raw snapshot or fixture.
3. Source status and data status remain separate.
4. Review decision links to candidate ID.
5. Promotion or quarantine output links to review decision.
6. Normalized CSV links to promotion and review.
7. Dry-run links to CSV manifest.
8. Report links to packet, dry-run and audit references.

## Real-Company Boundary

For MRVL / NVDA / AVGO, draft candidates are not facts. Quarantined data is not production data. Any missing link in the evidence chain blocks production readiness.
