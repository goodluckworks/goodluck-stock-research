# Stock Research Skill v0.2 Data Tools Validation

## 1. Scope

验证 v0.2 本地数据计算工具层是否能够：

- 只读取本地 CSV / JSON。
- 使用 Python 标准库运行。
- 对缺失文件、缺失字段和无效参数给出清晰错误。
- 生成包含来源、期间、币种、时间戳、假设、结果、限制和免责声明的 Markdown。

## 7. Issues Fixed During Validation

1. **Single-period trend wording**
   - Issue: A single-period financial input would return only `无法计算`.
   - Fix: Revenue growth and diluted shares trend now state `无法计算：需要至少两期数据`.

2. **Peer median contamination**
   - Issue: Initial peer statistics included the target company, which could distort the comparison baseline.
   - Fix: Mean, median, min, and max now exclude the target ticker. The raw table still includes the target.

3. **Duplicate peer tickers**
   - Issue: Duplicate ticker rows could overwrite calculation-origin metadata.
   - Fix: The peer script now rejects duplicate ticker values.

## 8. Known Limitations

- The scripts validate structure and arithmetic, not the truth or completeness of user-provided data.
- Financial ratio calculations use period-end assets and equity rather than average balances.
- The simplified DCF projects FCF directly and does not separately model revenue, margins, taxes, working capital, capex, or SBC.
- Peer comps do not automatically adjust for accounting standards, business mix, geography, capital structure, or cyclicality.
- Market-implied expectations hold current EV or market cap constant and are a reverse-engineering framework, not a forecast.
- No script performs currency conversion.
- No live API, web scraping, brokerage connection, credential handling, trading, or order execution is included.
