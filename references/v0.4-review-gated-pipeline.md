# v0.4 Review-Gated Pipeline

## 1. Positioning

v0.4 introduces a reusable offline / fixture-first / review-gated research pipeline. It integrates existing local evidence, XBRL candidate, review, promotion, sandbox CSV, v0.2.x ratio dry-run, packet and audit tools into a Skill-level workflow.

v0.4 is not production XBRL extraction. It is not live extraction. It does not approve real-company data.

## 2. Supported Pipeline Modes

- `fictional_sandbox_full`: EXMP fictional end-to-end sandbox.
- `fictional_sandbox_partial`: EXMP fictional partial-field sandbox with downstream impact.
- `real_company_review_only`: MRVL / NVDA / AVGO review-only evidence flow.
- `blocked_real_company_promotion_attempt`: explicit blocked-step proof for real-company promotion / CSV / dry-run attempts.

## 3. EXMP Fictional Sandbox

Run:

```bash
python3 goodluck-stock-research/pipeline/pipeline_orchestrator.py \
  --mode fictional_sandbox_full \
  --ticker EXMP \
  --company "Example Semiconductor Corp." \
  --output-dir goodluck-stock-research/examples/pipeline_runs/EXMP/full \
  --overwrite
```

The EXMP sandbox may produce:

- local candidate package
- review workbench
- quality score
- normalized review decision batch
- fictional promotion package
- normalized CSV sandbox
- v0.2.x ratio dry-run
- end-to-end audit
- sandbox research packet

All EXMP outputs must state fictional, sandbox, not investment data, not company fact and not for trading.

## 4. Real-Company Review-Only Flow

Run:

```bash
python3 goodluck-stock-research/pipeline/pipeline_orchestrator.py \
  --mode real_company_review_only \
  --ticker MRVL \
  --company "Marvell Technology, Inc." \
  --output-dir goodluck-stock-research/examples/pipeline_runs/MRVL/review_only \
  --overwrite
```

The real-company-shaped flow may produce candidate, workbench, quality and review evidence only.

It must not produce:

- promotion output
- approved normalized input
- populated normalized CSV
- v0.2.x dry-run
- investment conclusion

## 5. Why Real Companies Cannot Promote

The current XBRL prototype uses short local fixtures and excerpt drills. These are useful for review workflow testing, but they are not complete authoritative filings and not production parser output. Real-company promotion would require a separate policy, broader evidence, stronger parser coverage, review controls and source verification.

## 6. Why Real Companies Cannot Generate CSV or Dry-Run

CSV generation and v0.2.x dry-run consume approved normalized fields. MRVL, NVDA and AVGO do not have approved normalized inputs in this prototype. Running calculations on draft candidates would make unapproved data look more factual than it is.

## 9. v0.5 Direction

v0.5.0 adds a QA layer around the v0.4 pipeline:

- offline packet QA for pipeline manifests, packet manifests, dashboard references and blocked real-company paths
- artifact hygiene checks for tracked cache files, raw full filings, local path leaks and temporary evidence
- public-readiness audit with default `ready_for_public_release: No`

v0.5.0 does not make the repository public. It does not add live extraction, production parsing, real-company promotion, normalized CSV generation or v0.2.x dry-run for real companies.

Recommended v0.5.1+ work should stay offline and review-gated. Useful next targets:

- richer dashboard quality checks
- synthetic edge-case expansion
- real-company review packet QA drills without promotion
- no production parser until a separate public-readiness and parser-readiness audit passes

## 10. v0.6 Controlled Sandbox Extension

v0.6 adds a separate controlled real-company sandbox gate. It does not replace the v0.4 review-only rule.

Default state remains:

- MRVL / NVDA / AVGO are review-only.
- No real-company promotion.
- No real-company normalized CSV.
- No real-company v0.2.x dry-run.

Only an explicit v0.6 gate invocation may generate MRVL quarantined sandbox output, and that output must remain not production data, not investment data, not company fact until verified, manual-review-required, not for trading and not for public release.
