# v0.3.7 Review Ergonomics and Taxonomy Validation

## 1. Scope

This validation covers the v0.3.7 offline XBRL review layer:

- reviewer workbench ergonomics
- taxonomy relationship metadata
- mapping relationship review gates
- review checklist enforcement
- advisory review quality scoring
- MRVL / NVDA / AVGO real-filing-excerpt offline drills
- EXMP fictional extraction / workbench / quality / decision / promotion regression
- MRVL / NVDA / AVGO draft-only isolation

This release remains local-only and fixture-first. It does not add live extraction, production XBRL parsing, complete filing storage, real-company promotion, v0.2.x populated CSV generation, API keys, third-party dependencies, broker access, trading, orders or investment conclusions.
