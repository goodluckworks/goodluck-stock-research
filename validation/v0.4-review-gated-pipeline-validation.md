# v0.4 Review-Gated Pipeline Validation

## 1. Scope

v0.4 stabilizes the offline / fixture-first / review-gated research pipeline. It integrates partial-field handling, unresolved-field UX, pipeline orchestration, sandbox/review-only research packets and pipeline audit dashboard.

v0.4 is not live extraction and not a production XBRL parser.
