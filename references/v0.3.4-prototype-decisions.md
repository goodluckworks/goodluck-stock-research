# v0.3.4 Prototype Decisions

## 1. Parser Source

Decision:

- Use an offline, fixture-first parser.
- Read one local raw snapshot or fixture only.
- Perform no live extraction and no network request.
- Support a deliberately small inline XBRL-like fixture subset based on
  `data-xbrl-*` HTML attributes.
- Make no claim of production iXBRL, SEC taxonomy or arbitrary filing support.
- Do not parse the real MRVL live-smoke snapshot in v0.3.4.

## 2. Field Scope

Decision:

- Support the nine consolidated GAAP fields frozen in v0.3.3:
  `revenue`, `gross_profit`, `operating_income`, `net_income`,
  `operating_cash_flow`, `capital_expenditure`, `cash_and_equivalents`,
  `total_debt` and `diluted_shares`.
- Treat missing or ambiguous fields as structured unresolved records.
- Exclude segment, AI-only, Non-GAAP, normalized earnings, valuation and market
  data fields.
- Do not reconstruct gross profit or other missing values arithmetically.

## 3. Mapping Scope

Decision:

- Store a versioned JSON mapping registry.
- Use reviewed standard concept names plus explicitly selected fixture tags.
- Mark the registry `prototype_fixture_only`; it is not complete SEC taxonomy
  coverage.
- Permit an extension tag only when the mapping record explicitly allows and
  lists it.
- Prohibit first-match selection. Candidate selection must evaluate all facts
  for a field and enforce context, period, unit, dimensions and aggregation
  rules.

## 4. Review Gate

Decision:

- Keep every candidate at `draft_extracted_unreviewed`.
- Keep MRVL, NVDA and AVGO candidate runs draft-only.
- Require review records to validate against the candidate manifest,
  snapshot checksum and mapping version.
- Require explicit reviewer decisions before promotion.
- Permit only fictional EXMP review fixtures to be promoted in v0.3.4 tests.

## 5. Promotion Scope

Decision:

- Read approved or adjusted review records only.
- Generate a local, auditable `approved_normalized_draft.json`, not a v0.2.x
  financial CSV.
- Preserve candidate IDs, review IDs, decisions and approval timestamps.
- Block MRVL, NVDA and AVGO by default.
- Test promotion only with fictional EXMP data.
- Do not call calculation scripts or create investment conclusions.

## 6. Non-Goals

- Live SEC extraction or URL access.
- Production inline XBRL or instance-document parsing.
- Automatic tag discovery or taxonomy inference.
- Automatic approval of any real company value.
- Automatic normalized financial population for real companies.
- TTM bridges, segment extraction, extension-tag inference or amendment
  discovery.
- Broker, trading, order, recommendation, target-price or position behavior.
- Credential, environment-variable or third-party dependency use.

## 7. Acceptance Criteria

- Standard-library code reads local files only.
- Registry contains exactly one reviewed prototype record for each scoped
  field and a stable mapping version.
- Every accepted candidate includes value, source value, unit, period, context,
  dimensions, source locator, transformation, confidence, warnings and
  provenance.
- Missing, wrong-period, wrong-unit, dimensional, competing and aggregation
  conflicts become unresolved records.
- Capex sign transformation is explicit.
- Debt total/component overlap is unresolved.
- Review validation rejects missing approval, low-confidence approval and
  checksum/mapping mismatches.
- Promotion accepts only approved/adjusted fictional EXMP records.
- Real-company examples contain no approved normalized output.
- Adapter tests, XBRL tests, v0.2.x regressions and safety scans pass.
