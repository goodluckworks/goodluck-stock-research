# v0.2.2 Methodology Validation

## 1. Scope

本次验证覆盖 v0.2.2 的 DCF FCFF/UFCF/FCFE 估值桥、金额单位展示、GAAP 特殊项目与 normalized metrics 提示、peer forward growth provenance，以及虚构示例和 MRVL 真实输入回归。

测试仅使用本地 CSV/JSON，不联网、不读取 API key、不执行交易或下单。

## 2. Issues Addressed

| Issue | Severity | Fix | Files |
|---|---|---|---|
| FCFE 现金流被当作 enterprise cash flow 并再次扣减 net debt | High | 新增必填 `fcf_type`；FCFF/UFCF 扣减 net debt，FCFE 直接得到 equity value | `scripts/dcf_sensitivity.py`, `schemas/assumptions_schema.md` |
| 汇总金额和每股价值单位混淆 | Medium | 新增 `amount_unit`、`per_share_unit` 并在四个输出中显式展示 | 四个 scripts、四个 schemas、example/MRVL inputs |
| Raw GAAP 盈利可能受特殊项目影响但没有提示 | Medium | 增加 `special_items_notes` 和可选 normalized fields；保留 raw ratios 并输出 normalization warning | `ratio_calculator.py`, financials schema/input, financial references |
| Peer forward revenue growth 机械反推值可能被误读为 consensus | Medium | 增加 `forward_revenue_growth_source`；输出 growth source 和 derived warning | `peer_comps_table.py`, peer schema/input |

## 5. Unit Display Tests

- Aggregate values display `amount_unit`, including FCF, net debt, market cap, EV, revenue and required mature operating values.
- Per-share values display `per_share_unit`, including current price and DCF implied value per share.
- All eight generated outputs show:
  - `Currency: USD`
  - `Amount unit: USD millions`
  - `Per-share unit: USD/share`
- Multiples remain formatted with `x`; margins and growth remain formatted with `%`.
- Result: **Pass**.

## 9. Recommendation

- Ready for v0.2.2: **Yes**
- Ready to merge to main: **Yes, after user review of the generated MRVL and example outputs**
- Remaining limitations:
  - `OCF - capex` is only an FCFE research approximation and still requires manual accounting review.
  - The tool does not determine whether a supplied discount rate is economically appropriate for the selected FCF type.
  - Normalized metrics remain user-supplied and require a sourced reconciliation.
  - Market and peer data remain indicative and are not automatically cross-verified.
  - The optional Skill Creator validator could not run because its environment lacks PyYAML; Python compilation and all functional tests passed.
