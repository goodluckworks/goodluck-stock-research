## 8. Usability Decision

| Use Case | Decision | Notes |
|---|---:|---|
| Internal daily use | Yes | Fixture and controlled live smoke are understandable and auditable. |
| Unattended batch use | No | Live SEC smoke remains explicit and human-supervised. |
| Public release | Needs user decision | Functionally stable for private/internal workflow, but public release depends on repository disclosure preference. |

## 9. Remaining Limitations

- Live SEC smoke verifies controlled access and manifest creation; it is not a bulk ingestion or full parser accuracy benchmark.
- Market data CSV fallback remains user-provided or controlled-source based; v3.0.1 does not add paid vendor API integrations.
- Reports remain drafts until a human reviews source manifests, caveats, data quality and approval gate status.
