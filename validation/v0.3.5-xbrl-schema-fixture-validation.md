# v0.3.5 XBRL Schema and Fixture Validation

## 1. Scope

This validation covers the v0.3.5 offline-only XBRL package hardening work:

- Machine-readable schemas for extraction, review, mapping and promotion artifacts.
- Standard-library schema validation.
- Offline `data_attr`, `inline_like` and minimal `instance_xml` fixture subsets.
- Package-level audit across extraction, review and promotion outputs.
- EXMP fictional extraction / review / promotion.
- MRVL / NVDA / AVGO synthetic real-company-shaped draft-only extraction.
- v0.2.x local CSV / JSON script regression.
- Adapter regression.
- Safety scan.

v0.3.5 remains fixture-first and offline. It does not implement live extraction, production iXBRL parsing, real-company promotion, populated v0.2.x CSV generation, broker integration, trading execution or investment conclusions.

## 12. Safety Scan

Broad scan command:

```bash
grep -RniE "requests|urllib|http.client|socket|aiohttp|yfinance|openbb|api_key|token|password|secret|broker|order|trade|buy|sell|os.environ|subprocess|selenium|playwright" goodluck-stock-research/scripts goodluck-stock-research/adapters goodluck-stock-research/xbrl goodluck-stock-research | head -600
```

Classification:

1. SEC adapter allowed `urllib` implementation remains in the existing controlled SEC adapter.
2. Documentation and tests contain prohibition terms by design.
3. Ordinary finance terms such as buybacks and sell-side appear in research references.
4. Actual code risk: none found.

Narrow XBRL code scan found no network imports, credential reads, `os.environ`, subprocess, Selenium, Playwright, browser automation, broker/trading/order implementation, investment conclusion output, real-company auto approval or v0.2.x script invocation.
