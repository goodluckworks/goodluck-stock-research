# Quick Tearsheet

## 使用规则

- 不允许留空字段。
- 未知内容必须明确写：`未披露`、`未验证`、`暂无可靠来源`、`不适用` 或 `待核实`。
- 所有关键未知项必须进入 `下一步需要核实`。
- 所有市场数据和估值倍数必须注明 source + timestamp + market session + currency；估值倍数还必须注明 trailing / forward / TTM / NTM 口径。
- 如果市场数据来自 StockAnalysis、Yahoo Finance、CompaniesMarketCap、Macrotrends 等二级公开页面，必须标注 `indicative` 或 `待交叉验证`，并说明是否为实时、延迟、估算或页面快照。
- 如果无法确认数据更新时间，必须写 `timestamp 未验证`；不允许把二级页面数据当作公司官方披露。
- 最终状态必须使用 `references/status-taxonomy.md` 定义的枚举。
- 快速研究卡片也必须区分事实、推断、假设和观点，不能用未验证数据支撑高置信度结论。
