# v0.3.4 Offline XBRL Extraction Validation

## 1. Scope

This validation covers the offline, fixture-first, draft-only v0.3.4 XBRL
candidate prototype, human review validator and fictional EXMP promotion test.
It does not cover live extraction or production iXBRL parsing.

## 2. Prototype Decisions

- Parser source: one local artificial `data-xbrl-*` HTML fixture.
- Field scope: nine consolidated GAAP fields.
- Mapping: versioned `prototype_fixture_only` JSON registry.
- Selection: evaluate all mapped facts; first-match behavior is prohibited.
- Review: every candidate remains `draft_extracted_unreviewed`.
- Promotion: validated approve/adjust records only.
- Real-company rule: MRVL, NVDA and AVGO promotion blocked by default.
- Example promotion: fictional EXMP only.
- Output boundary: promotion creates an auditable draft, not a v0.2.x CSV.

1. Allowed `urllib` in the existing SEC adapter.

4. Actual code risk: none.

- No network import or URL opening.
- No `os.environ` or credential read.
- No subprocess or shell command.
- No Selenium, Playwright or browser automation.
- No broker, order or trading client.
- No v0.2.x calculation-script invocation.
