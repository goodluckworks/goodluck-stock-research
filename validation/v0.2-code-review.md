## 3. Formula Review

### ratio_calculator.py

- Revenue growth 使用相邻输入行：`current / previous - 1`。
- Gross margin = `gross_profit / revenue`。
- Operating margin = `operating_income / revenue`。
- Net margin = `net_income / revenue`。
- Operating cash flow margin = `operating_cash_flow / revenue`。
- Free cash flow = `operating_cash_flow - abs(capital_expenditure)`。
- FCF margin = `free_cash_flow / revenue`。
- ROE = `net_income / shareholders_equity`。
- ROA = `net_income / total_assets`。
- Net debt = `total_debt - cash_and_equivalents`。
- Debt / equity = `total_debt / shareholders_equity`。
- Current ratio = `current_assets / current_liabilities`。
- SBC / revenue、AR / revenue、Inventory / revenue 公式正确。
- Diluted shares trend 使用相邻期间；只有一期时明确输出 `无法计算：需要至少两期数据`。
- 分母为 0 或字段为空时返回 `无法计算`，不会抛出除零错误。
- Capex 正负号均按现金流出绝对值处理；schema 与输出限制已明确披露该口径。

Result: **Pass**.

### dcf_sensitivity.py

- FCF 按各 case 的年度增长率逐年滚动。
- Terminal value 使用 Gordon Growth：
  `terminal_fcf * (1 + terminal_growth) / (discount_rate - terminal_growth)`。
- 每个 discount rate 必须大于每个 terminal growth rate。
- Enterprise value = 显式预测 FCF 现值 + terminal value 现值。
- Equity value = enterprise value - net debt。
- Value per share = equity value / diluted shares。
- Diluted shares 必须大于 0。
- Net debt 允许为负数，并正确表示 net cash 对 equity value 的增加。
- 输出明确说明 DCF 是研究工具，不是目标价承诺或买卖信号。
- 修复后拒绝非有限数字、JSON 布尔伪数字和 `discount_rate <= -100%`。

Result: **Pass after fix**.

### peer_comps_table.py

- 目标 ticker 使用 case-insensitive 精确匹配。
- 缺失倍数时，依次尝试：
  - EV/Sales = `enterprise_value / revenue_ttm`
  - EV/EBITDA = `enterprise_value / ebitda_ttm`
  - P/E = `market_cap / net_income_ttm`
  - P/FCF = `market_cap / free_cash_flow_ttm`
- 分母为 0 或负数时不生成误导性正倍数。
- Mean、median、min、max 只使用有效正倍数，且排除目标公司。
- 数据缺口和潜在不可比项单独列出。
- 明确禁止用 peer mean / median 直接形成买卖判断。

Result: **Pass**.

### implied_expectations.py

- EV/Sales 框架保持当前 EV 不变：
  `required revenue = enterprise value / mature EV/Sales`。
- P/E 框架保持当前 market cap 不变：
  `required net income = market cap / mature P/E`。
- 在股数不变假设下，net income scale-up 等价于 EPS scale-up；输出明确披露该假设。
- P/FCF 框架：
  `required FCF = market cap / mature P/FCF`。
- CAGR = `(required value / current value) ** (1 / years) - 1`。
- `years_to_maturity <= 0` 会报错。
- 当前倍数缺失时可由基础字段回算；基础字段不足或非正时明确输出无法计算与数据缺口。
- Mature multiple 高于 current multiple 时允许负 CAGR，并说明这是机械反推，不是预测。

Result: **Pass**.

独立函数断言覆盖了增长率、除法保护、DCF 终值/现值/权益桥接、peer multiple 和 implied CAGR，全部通过。

- Rejected DCF growth rates below `-100%`.
- Added input/output same-path protection to all four tools.
- Updated scripts README and four schemas to document these constraints.
- Recompiled all scripts and reran normal examples, 28 edge cases, formula assertions, security scans, and whitespace checks.
