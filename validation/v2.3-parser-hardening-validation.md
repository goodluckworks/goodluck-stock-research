# v2.3 Parser Hardening Validation

Date: 2026-07-07

## Scope

v2.3 hardens the scoped production parser for real-filing edge cases without expanding into unsupported issuers or complex segment extraction.

## Coverage

| Case | Result | Notes |
|---|---:|---|
| Dimensions | Pass | Dimensional facts require explicit reviewed mapping. |
| Multiple contexts | Pass | Multiple contexts without selected context are unresolved. |
| Duration vs instant | Pass | Income/cash-flow fields require duration; balance-sheet/share fields require instant. |
| Unit scaling | Pass | Unsupported units are unresolved. |
| Negative values / capex sign | Pass | Capex sign must be explicit. |
| Total debt vs components | Pass | Overlapping debt components are unresolved. |
| Cash vs restricted cash | Pass | Cash including restricted cash is unresolved. |
| Diluted vs basic shares | Pass | Basic shares cannot fill diluted shares. |
| Missing gross profit | Pass | Existing parser keeps unsupported/missing fields unresolved. |
| Taxonomy extensions | Pass | Extensions require reviewed mapping. |
| Amendments/restatements | Pass | Amendment status is required when amended. |
| Unsupported issuers | Pass | Banks, insurers, funds and foreign/unsupported issuers remain blocked. |
