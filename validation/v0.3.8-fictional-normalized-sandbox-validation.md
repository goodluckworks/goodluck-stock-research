# v0.3.8 Fictional Normalized Sandbox Validation

## 1. Scope

This validation covers `stock-research-v0.3.8`, which adds a fictional-only end-to-end sandbox:

```text
EXMP fictional fixture
  -> candidate extraction
  -> review quality
  -> normalized review decision batch
  -> approved-field promotion
  -> normalized v0.2.x CSV sandbox
  -> ratio_calculator dry-run
  -> end-to-end audit
```

Boundary: EXMP fictional only. MRVL, NVDA and AVGO remain draft-only and blocked from promotion, normalized CSV generation and v0.2.x dry-run.
