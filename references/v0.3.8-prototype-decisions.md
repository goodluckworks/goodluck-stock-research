# v0.3.8 Prototype Decisions

## 1. Purpose

v0.3.8 creates a strictly isolated fictional-only end-to-end sandbox from reviewed XBRL candidates to a populated v0.2.x-compatible normalized CSV and a ratio-calculator dry-run. The goal is to prove auditability and boundary enforcement, not to produce investment data.

## 2. Decisions

### Fictional-only normalized output

- Only EXMP fictional data may produce a populated normalized CSV sandbox.
- MRVL, NVDA and AVGO remain blocked.
- Output is sandbox data, not production data, not company facts and not investment data.

### Separation of promotion and calculation

- Promotion creates the approved-field package and does not run v0.2.x scripts.
- The normalized CSV sandbox generator is a separate explicit command after promotion.
- The v0.2.x ratio dry-run is another separate explicit command.
- No DCF, peer comps or implied expectations dry-run is included in v0.3.8.

### CSV auditability

- Every populated CSV field must link to review record, candidate ID, mapping version, promotion ID and snapshot SHA.
- Unsupported fields remain blank or explicitly unresolved, never guessed.
- The CSV audit file must preserve source approved value, transformation, unit, period, confidence and provenance reference.

### Sandbox labeling

- Generated CSV, manifest, audit report and dry-run output must state fictional, sandbox, not investment data, not company fact, not production research and not for trading.
- The sandbox label is a hard gate, not just display text.

### Real-company safety

- Real-company CSV generation is blocked by default.
- There is no real-company CSV override in v0.3.8.
- Real-company v0.2.x dry-run is blocked.

## 3. Non-Goals

- No live extraction.
- No production iXBRL parser.
- No complete real filing ingestion.
- No real-company approved normalized input.
- No populated v0.2.x CSV for MRVL, NVDA or AVGO.
- No v0.2.x dry-run for real companies.
- No target price, buy/sell/hold, position size, research status, broker, order or trading output.
- No new third-party dependencies, credentials or environment-variable reads.

## 4. Acceptance Criteria

- EXMP can generate `normalized_financials_sandbox.csv`, `normalized_csv_manifest.json`, `normalized_csv_audit.json` and `normalized_csv_report.md`.
- EXMP sandbox CSV can run through `ratio_calculator.py` via a local in-process dry-run wrapper.
- End-to-end audit verifies extraction, quality score, review batch, promotion package, sandbox CSV and dry-run output.
- MRVL, NVDA and AVGO CSV generation and dry-run attempts fail with explicit blocking errors.
- Existing XBRL tests, adapter tests and v0.2.x script regressions continue to pass.
- Safety scan shows no new network, credential, subprocess, broker/trading/order or investment-conclusion implementation risk.

## 5. Stop Conditions

- Any real-company normalized CSV or dry-run output is generated.
- Any promotion path bypasses mapping review, review quality score, checklist or normalized review batch.
- Any generated CSV lacks sandbox / fictional / not-investment labels.
- Any generated CSV field lacks audit references.
- Any v0.2.x script is invoked from promotion.
- Any target price, recommendation, position size, broker, order or trading behavior appears.
