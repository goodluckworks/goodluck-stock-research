# v0.3.6 Prototype Decisions

## 1. Purpose

v0.3.6 adds governance around the offline XBRL prototype: mapping review, reviewer workbench generation, review decision collection, promotion isolation, and expanded synthetic edge-case coverage. It remains a local-only prototype and does not perform production extraction.

## 2. Decisions

### Mapping review workflow

- Mapping records require review status.
- Only approved mapping versions may be used for promotion.
- Draft / reviewed / approved / superseded lifecycle must be explicit.
- Superseded mappings invalidate dependent candidate and review packages.
- Mapping review is separate from extraction, candidate review, and promotion.

### Reviewer workbench

- Candidate packages can be rendered into human-readable Markdown.
- Workbench must show candidate value, source tag, period, unit, context, dimensions, transformation, warning flags and competing candidates.
- Workbench must never imply approval.
- Workbench templates are reviewer input files, not normalized review batches.

### Review decision flow

- Reviewer decisions are stored separately from candidates.
- Decisions must reference candidate IDs.
- Decisions must retain reviewer notes and audit timestamps.
- Adjustments must preserve extracted and approved value.
- Collector output is the only review-batch input accepted by v0.3.6 promotion.

### Promotion isolation

- Fictional EXMP is the only tracked promotion example.
- MRVL / NVDA / AVGO promotion is blocked by default.
- Real-company promotion requires a future explicit approval flag and separate release.
- Promotion requires approved mapping review, normalized review batch, decision log and audit references.

### Edge-case expansion

- Add synthetic fixtures for extension, restatement, debt, capex, cash and shares edge cases.
- Edge-case fixtures are short artificial files and not authoritative company data.

## 3. Non-Goals

- No live extraction.
- No production iXBRL parser.
- No full 10-K / 10-Q parser.
- No real-company auto approval or promotion.
- No real-company approved normalized input.
- No populated v0.2.x CSV generation.
- No target price, buy/sell/hold, position size or research status output.
- No credentials, broker integration, order routing or trading.

## 4. Acceptance Criteria

- Mapping review approved/rejected/superseded lifecycle is testable.
- Reviewer workbench examples exist for EXMP, MRVL, NVDA and AVGO.
- Review decision collector normalizes valid decisions and rejects incomplete decisions.
- EXMP fictional promotion requires approved mapping review and normalized review batch.
- MRVL / NVDA / AVGO have no promotion output.
- Synthetic edge-case tests cover taxonomy drift, extension, restatement, debt, capex, cash, share-duration, unit, materiality and dimensional revenue cases.
- Existing XBRL, adapter and v0.2.x regressions pass.

## 5. Stop Conditions

- Any code performs live extraction or network XBRL parsing.
- Any code reads credentials or environment variables.
- Any mapping status other than approved can be promoted.
- Any superseded mapping can be promoted.
- Raw workbench templates can be promoted directly.
- Real-company-shaped fixtures are auto-approved or promoted.
- Any output contains target price, recommendation, position size, broker, trade or order logic.
