# v0.3.5 Prototype Decisions

## 1. Purpose

v0.3.5 hardens the offline XBRL prototype by adding machine-readable validation, stricter package consistency checks, and more realistic local fixture subsets. It remains an offline-only, fixture-first prototype for draft candidate extraction and review workflow testing.

## 2. Decisions

### Machine-readable validation

- Use standard-library validators.
- Do not add a `jsonschema` dependency.
- Validate candidate, manifest, mapping, review and promotion outputs.
- Treat validation as a contract check, not as approval of financial facts.

### Parser fidelity

- Continue fixture-first.
- Support the artificial `data-xbrl-*` fixture subset from v0.3.4.
- Add a more realistic offline inline-XBRL-like subset.
- Add a minimal offline instance-document subset for short artificial XML fixtures.
- Do not claim production iXBRL support.
- Do not open external taxonomy, schema, image, JavaScript, CSS, or filing URLs.

### Real-company policy

- MRVL / NVDA / AVGO remain synthetic real-company-shaped fixtures.
- Their candidates remain draft/unreviewed.
- Promotion remains blocked by default.
- Real-company-shaped fixtures are not authoritative financial data.

### Promotion policy

- Fictional EXMP only may be promoted in tracked tests.
- Promotion remains separate from extraction.
- Promotion does not create v0.2.x CSV.
- Promotion does not invoke ratio, DCF, peer comps, implied expectations, adapter, or report-generation scripts.

## 3. Non-Goals

- No live extraction.
- No production iXBRL parser.
- No full 10-K / 10-Q parser.
- No SEC URL field extraction.
- No real-company approved normalized input.
- No populated v0.2.x input CSV generation.
- No investment conclusion, target price, buy/sell/hold, position size, or research status output.
- No broker, trading, order, credential, API key, token, password, or secret handling.

## 4. Acceptance Criteria

- Machine-readable schema files exist for manifest, candidate, unresolved field, provenance, mapping, review, promotion manifest, and approved normalized draft outputs.
- A standard-library schema validator can validate single files and package directories.
- EXMP extraction, review, promotion, schema validation, fixture-format tests, and package audit pass.
- MRVL / NVDA / AVGO candidate extraction passes and remains draft-only.
- No real-company promotion package or approved normalized input exists.
- v0.2.x local calculation scripts, adapter tests, existing XBRL tests, compile checks, and safety scan pass.

## 5. Stop Conditions

- Any XBRL code performs network access or opens external URLs.
- Any code reads environment variables for credentials.
- Any code invokes broker, order, trade, buy, sell, hold, position-size, or investment-conclusion behavior.
- Any real-company fixture is auto-approved or promoted.
- Any candidate lacks provenance fields.
- Review or promotion can bypass approve/adjust rules.
- Parser reports imply production iXBRL coverage.
- First-match extraction replaces unresolved handling for competing facts.
