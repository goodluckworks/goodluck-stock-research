This validation covers the Medium implementation gap exposed by the AVGO regression: v0.2.3 could describe acquisition accounting only in prose and could not calculate goodwill, intangible-asset or acquisition-expense ratios.

|---|---|---|---|

| Segment-complex companies could be over-read from consolidated tools | Method limitation | Documented that segment mix and SOTP remain research-report judgments | Valuation reference and template |

## 5. Segment Case Handling

- The four tools remain consolidated financial calculators; no unsupported segment-profit model was added.
- `peer_group`, `comparability_status`, `comparability_notes` and `include_in_core_stats` provide structured valuation context.
- Segment revenue, segment profitability, organic growth and SOTP remain report-layer analyses requiring company-specific evidence.
- This is a Method limitation, not an unresolved implementation defect, and it does not block Phase 4.

## 7. Safety Review

- Standard library only.
- No network imports, URL-opening logic, browser automation or web scraping.
- No API key, token, password, secret, environment-variable or credential-store reads.
- No subprocess or shell-command execution in the Python tools.
- No broker connection, order routing or trading execution.
- Scripts read the local `--input` path and write the user-selected local Markdown `--output` path.
