# v0.3.7 Prototype Decisions

## 1. Purpose

v0.3.7 improves the offline XBRL review workflow created in v0.3.6. The goal is better human review ergonomics, explicit taxonomy relationship metadata, advisory review quality scoring and short real-filing-excerpt drills. This release remains fixture-first, local-only and review-gated.

## 2. Decisions

### Review Ergonomics

- Reviewer workbench must be human-readable before machine-actionable.
- Workbench must not imply approval.
- Every candidate must include checklist prompts.
- Every warning must have a review instruction.
- Competing candidates must be shown as a comparison problem, not as a selection shortcut.
- Confidence must be explained as extraction confidence only, not approval status.

### Taxonomy Relationship Metadata

- Relationship metadata is fixture-level and review-oriented.
- It is not a production taxonomy resolver.
- Extension relationship evidence is required before higher confidence.
- Missing relationship evidence blocks approval readiness.
- Standard concept metadata may be fixture-supplied; it is still not authoritative taxonomy coverage.

### Real-Filing-Excerpt Drill

- Use short, license-safe excerpts only.
- Do not store full filings.
- Do not represent excerpt outputs as verified full-company financials.
- MRVL/NVDA/AVGO remain draft-only.
- Drill outputs may include candidates, workbenches and quality scores, but never promotion packages.

### Review Quality Scoring

- Scores are advisory.
- Scores do not approve fields.
- Low score blocks readiness but does not alter raw candidates.
- Blocking issues must be visible to reviewers and promotion gates.

### Promotion Isolation

- EXMP remains the only tracked promotion example.
- Real-company promotion remains blocked.
- Promotion requires normalized review batch, checklist evidence, quality score reference and approved mapping review.

## 3. Non-Goals

- No production XBRL parser.
- No live extraction.
- No complete real filing storage.
- No automated approval for MRVL/NVDA/AVGO.
- No approved normalized input for real companies.
- No populated v0.2.x CSV generated by the XBRL path.
- No target price, recommendation, buy/sell/hold, position size or research status output.
- No credentials, broker integration, order routing or trading.

## 4. Acceptance Criteria

- Reviewer workbench includes summary, checklist prompts, relationship metadata, warning instructions, competing-candidate comparison and explicit not-approved banner.
- Candidate packages include taxonomy relationship metadata and review checklist placeholders.
- Review quality scorer emits JSON and Markdown score artifacts for EXMP, MRVL, NVDA and AVGO.
- Decision collector rejects approve/adjust decisions with missing checklist, unchecked relationship, not-ready quality score or blocking issues.
- Package auditor checks relationship metadata, checklist, quality score references and real-company promotion blocking.
- Real-filing-excerpt drills are short, local, non-authoritative and unpromoted.
- Existing v0.2.x, adapter and XBRL regressions pass.

## 5. Stop Conditions

Stop and fix before release if any of the following appear:

- Any live extraction or network XBRL extraction code.
- Any credential, broker, order or trading code.
- Any real-company approved normalized input or promotion output.
- Any promotion path that bypasses mapping review, checklist, normalized review batch or quality score reference.
- Any target price, recommendation, buy/sell/hold, position size or research status output.
- Any real-filing excerpt that looks like or claims to be a complete filing.
