# v0.6.0 Controlled Real-Company Sandbox Validation

Date: 2026-07-03

## 1. Scope

v0.6.0 adds a controlled, explicit and quarantined real-company sandbox gate for one MRVL drill.

This phase does not add live extraction, production iXBRL parsing, public release, automated real-company promotion, DCF, peer comps, implied expectations, full research report generation, broker/trading/order logic, credentials, target price, buy/sell/hold, position size or research status.
